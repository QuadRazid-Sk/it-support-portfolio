# 12. Закончилось место на диске C

**Симптом.** Система пишет о нехватке места, обновления не ставятся, не сохраняются файлы, тормозит почта.

**Причина.** Журналы, обновления, теневые копии, профили пользователей, файлы на рабочем столе и в загрузках.

**Решение.**

1. Посмотреть объёмы: Get-PSDrive C и Storage Sense в параметрах.
2. Очистить временные файлы: %TEMP%, C:\Windows\Temp, кэш обновлений через cleanmgr.
3. Проверить теневые копии: vssadmin list shadowstorage — при необходимости уменьшить лимит по согласованию.
4. Найти крупные каталоги: WinDirStat, затем переместить пользовательские файлы на сетевой диск или диск данных.
5. Очистить журналы событий старше 30 дней, проверить размер папки WinSxS через DISM /Online /Cleanup-Image.

**Проверка.** Свободно не менее 15% системного диска, обновления устанавливаются.

**Когда эскалировать.** Если место уходит само за сутки — искать причину: дампы, циклический журнал, бэкап-клиент, это задача второй линии.
