# 19. Excel открывает файл в защищённом просмотре или блокирует его

**Симптом.** Файл из письма или с сетевого диска открывается только для чтения, сверху жёлтая полоса «Защищённый просмотр».

**Причина.** Файл получен из внешнего источника, стоит метка блокировки, расположение не входит в доверенные.

**Решение.**

1. Понять, откуда файл: почта, интернет, сетевой диск.
2. Снять метку блокировки: свойства файла → «Разблокировать».
3. Добавить расположение в доверенные: параметры Excel → Центр управления безопасностью → Надёжные расположения.
4. Проверить режим «Защищённый просмотр» и отключать его выборочно, не целиком.
5. Убедиться, что файл открывается на редактирование и сохраняется.

**Проверка.** Файл открывается на редактирование, изменения сохраняются.

**Когда эскалировать.** Если файл повреждён или блокируется политикой организации — восстановление из бэкапа, заявка администратору.
